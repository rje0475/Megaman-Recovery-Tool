# Security Policy

## Supported version

Versie 1.0.x ontvangt beveiligingsupdates tijdens de eerste releasecyclus.

## Reporting a vulnerability

Publiceer kwetsbaarheden, tokens, persoonlijke muziekdata of lokale paden niet
in een publieke issue. Meld een kwetsbaarheid via GitHub Private Vulnerability
Reporting. Beschrijf impact, reproduceerstappen en een eventuele mitigatie.

De maintainers proberen binnen zeven dagen ontvangst te bevestigen. Deel geen
Spotify- of YouTube-credentials in logs of bijlagen.
